# 문제: 자동완성 시스템 (Trie)

## 설명

자동완성 기능은 사용자가 입력한 문자열의 접두사에 기반하여 가능한 단어 목록을 제시하는 기능입니다. 이 문제에서는 주어진 문자열 목록을 Trie 구조에 저장한 뒤, 특정 접두사로 시작하는 모든 단어를 사전 순으로 반환하는 시스템을 구현합니다.

---

## 동작 개요

- 여러 개의 문자열을 Trie에 저장합니다.
- 특정 접두사(prefix)가 주어지면, 이 prefix로 시작하는 모든 단어를 찾아 반환합니다.
- 반환 결과는 **사전 순으로 정렬된 배열**입니다.
- 중복된 단어는 한 번만 저장합니다.

---

## 참고 사항

- Trie는 문자열 검색과 삽입에 효율적인 자료구조입니다.
- 이 문제에서는 **문자 단위 노드 구조의 표준 Trie**를 기반으로 구현합니다.
- prefix가 일치하는 경로를 따라 내려간 후, 해당 하위 노드들을 탐색하여 단어들을 수집합니다.

---

## 예시 출력 요약

| 입력 단어 목록                                      | 접두사(prefix) | 예상 출력                           |
|------------------------------------------------------|----------------|--------------------------------------|
| `["apple", "app", "application", "banana"]`          | `"a"`          | `["app", "apple", "application"]`    |
| `["apple", "app", "application", "banana"]`          | `"app"`        | `["app", "apple", "application"]`    |
| `["apple", "app", "application", "banana"]`          | `"ban"`        | `["banana"]`                         |
| `["apple", "app", "application", "banana"]`          | `"z"`          | `[]`                                 |
