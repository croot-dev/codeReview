# 🌲 문제: Trie에 문자열 삽입 - 공통 접두사 처리

## 🧾 설명

Trie는 문자열을 저장하기 위한 트리 구조로, 각 노드는 문자열의 한 글자를 나타내며, 자식 노드는 다음 글자를 나타냅니다. Trie는 문자열 검색과 삽입에 효율적입니다.

이 문제에서는 **특정 규칙에 따라 문자열을 Trie에 삽입**할 때, **루트 노드를 제외한 비어 있지 않은 노드의 개수**를 리턴하는 프로그램을 작성합니다.

---

## 동작 개요

1. 문자열 `S`를 저장하기 위해 루트 노드부터 탐색을 시작합니다.
2. 루트 노드에서는 문자열 `S`의 첫 글자에 해당하는 분기(branch)를 통해 탐색합니다.
3. 탐색된 노드 `N`에 대해 다음 두 가지 중 하나를 수행합니다:
   - 3-1. `N`이 비어 있다면, `N`에 문자열 `S`를 저장하고 종료합니다.
   - 3-2. `N`이 비어 있지 않다면, 4번 단계로 진행합니다.
4. 노드 `N`이 저장한 문자열 `T`와 삽입할 문자열 `S`를 비교합니다:
   - 4-1. `T == S`라면, 삽입을 종료합니다.
   - 4-2. `T != S`라면, 5번 단계로 진행합니다.
5. 문자열 `T`와 `S`의 가장 긴 공통 접두사 `P`를 구합니다.  
   이때 `T'`와 `S'`는 각각 `T`와 `S`에서 `P`를 제외한 나머지 문자열입니다.
   - 5-1. 만약 `P == T`인 경우:  
     노드 `N`을 루트 노드처럼 간주하고, 그 하위로 `S'`를 삽입하기 위해 1번부터 다시 수행합니다.
   - 5-2. 만약 `P == S`인 경우:  
     `P`를 저장하는 새로운 노드 `M`을 만들고, `N`의 부모 노드에서 `T` 대신 `P`를 저장하게 합니다. 이후 `N`은 `M`의 자식 노드가 됩니다.
   - 5-3. `P`가 둘 다 아닌 경우:  
     `P`를 저장하는 새로운 노드 `M`을 만든 후,  
     - `M`의 자식 노드로 `T'`를 저장한 노드(`N`)를 연결하고,
     - 새로운 자식 노드로 `S'`를 저장한 노드도 만들어 `M`에 연결합니다.
     - 이후 `M`을 루트로 간주하고 1번부터 `S'` 삽입을 다시 시작합니다.
6. 위 과정을 통해 Trie를 완성한 후, **루트 노드를 제외한 비어 있지 않은 노드의 개수**를 반환합니다.

---

## 입력 형식

- 문자열의 리스트 `words`가 주어집니다.  
  예: `["apple", "app", "apt", "bat"]`

--- 

## 출력 형식

- Trie에 삽입된 **루트 노드를 제외한 비어 있지 않은 노드의 수**를 정수로 반환합니다.

---

## 예시 출력 요약

| 입력                                 | 예상 출력 |
|--------------------------------------|------------|
| `["apple", "app", "apt"]`            | `5`        |
| `["car", "card", "cards", "care"]`   | `4`        |
| `["hello", "hell", "heaven", "heavy"]` | `5`      |
| `["abc"]`                            | `1`        |
| `[]`                                 | `0`        |
